# BUYE IELTS — Phase 2G
Adds a dedicated Practice Centre to the Phase 2F learning platform.

Included:
- Listening Practice 1: 20 original objective questions
- Academic Reading Practice 1: 20 original objective questions
- General Training Reading Practice 1: 20 original objective questions
- Timed test flow, answer selection, score, answer review
- Approximate /40 practice band guidance
- Writing Task 1 + Task 2 workspace
- Speaking Parts 1–3 simulation
- Criteria-based self-review for Writing and Speaking
- Original BUYE prompts/questions

Important: IELTS officially uses 40 questions in Listening and Reading, with one mark per correct answer; exact band conversion can vary by test version. BUYE's displayed band is therefore a practice estimate, not an official result. Writing and Speaking require examiner assessment.

Listening in this phase is deliberately a text-based simulation. Do not label it as an authentic Listening test until original audio assets are added.

Run:
python -m http.server 8000
Open http://localhost:8000/practice.html
