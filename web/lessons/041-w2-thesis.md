# BUYE IELTS Module 041: Write a Direct Thesis

**Track:** Writing Task 2  
**Goal:** Make your position visible.

## Lesson
A thesis should answer the question directly rather than announce that you will discuss it.

## Practice
Write a thesis for: Should cities restrict private cars?

## Suggested answer / rationale
A clear position supporting or opposing restrictions.
