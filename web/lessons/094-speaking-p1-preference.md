# BUYE IELTS Module 094: Part 1: Preferences

**Track:** Speaking  
**Goal:** Explain choices.

## Lesson
Use because, whereas, compared with and especially to explain preferences.

## Practice
Tea or coffee? Explain.

## Suggested answer / rationale
