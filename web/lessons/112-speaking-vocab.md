# BUYE IELTS Module 112: Speaking Vocabulary: Flexible Words

**Track:** Speaking  
**Goal:** Avoid repeating one basic word.

## Lesson
Build families around common topics and learn natural combinations.

## Practice
Replace repeated “good” in three contexts.

## Suggested answer / rationale
effective / enjoyable / beneficial.
