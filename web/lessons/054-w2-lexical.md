# BUYE IELTS Module 054: Use Precise Topic Vocabulary

**Track:** Writing Task 2  
**Goal:** Choose accurate terms rather than obscure words.

## Lesson
Build vocabulary around the topic and function: cause, effect, evaluation, comparison.

## Practice
Replace “a lot of cars” in formal writing.

## Suggested answer / rationale
a large number of private vehicles.
