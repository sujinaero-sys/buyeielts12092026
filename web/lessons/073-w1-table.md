# BUYE IELTS Module 073: Table Data Selection

**Track:** Writing Task 1  
**Goal:** Select useful figures.

## Lesson
Do not report every number. Choose extremes, clusters and meaningful contrasts.

## Practice
Select three figures from a six-category table.

## Suggested answer / rationale
Highest, lowest and representative comparison.
