# BUYE IELTS Module 027: Multiple Choice Evidence

**Track:** Reading  
**Goal:** Choose only an option supported by the text.

## Lesson
Underline the core claim in each option and prove or disprove it from the passage.

## Practice
If three options are mentioned but only one answers the question, choose the one that completes the required relationship.

## Suggested answer / rationale
Evidence-supported option
