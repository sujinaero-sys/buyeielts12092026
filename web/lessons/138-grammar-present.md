# BUYE IELTS Module 138: Present Simple vs Continuous

**Track:** Grammar  
**Goal:** Choose tense by meaning.

## Lesson
Present simple suits routines/facts; continuous highlights temporary or current activity.

## Practice
“People increasingly use online banking.” Which tense and why?

## Suggested answer / rationale
Present simple for a current trend/general fact.
