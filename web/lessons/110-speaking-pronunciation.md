# BUYE IELTS Module 110: Pronunciation: Chunking

**Track:** Speaking  
**Goal:** Speak in meaningful groups.

## Lesson
Pause between ideas rather than every word. Stress key content words.

## Practice
Mark pauses in a two-sentence answer.

## Suggested answer / rationale
Any sensible thought groups.
