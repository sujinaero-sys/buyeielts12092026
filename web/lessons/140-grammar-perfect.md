# BUYE IELTS Module 140: Present Perfect in IELTS

**Track:** Grammar  
**Goal:** Use the perfect for changes and experience.

## Lesson
It is useful when a time period continues or the result matters now.

## Practice
Write a sentence about technology changing in recent years.

## Suggested answer / rationale
Accurate present perfect.
