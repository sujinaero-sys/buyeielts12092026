# BUYE IELTS Module 058: Compare Alternatives

**Track:** Writing Task 2  
**Goal:** Evaluate options using the same criteria.

## Lesson
Compare cost, access, effectiveness or long-term impact rather than making unrelated lists.

## Practice
Compare public and private transport on access.

## Suggested answer / rationale
Public transport is more accessible at scale.
