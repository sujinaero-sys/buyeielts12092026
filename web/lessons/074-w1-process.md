# BUYE IELTS Module 074: Process Description

**Track:** Writing Task 1  
**Goal:** Show stages in order.

## Lesson
Identify start/end, number of stages and whether the process is linear or cyclical.

## Practice
Outline a six-stage recycling process.

## Suggested answer / rationale
Input → sorting → processing → production → use → collection.
