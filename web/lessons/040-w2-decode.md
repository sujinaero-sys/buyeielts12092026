# BUYE IELTS Module 040: Decode the Question

**Track:** Writing Task 2  
**Goal:** Identify the exact task before generating ideas.

## Lesson
Underline topic, instruction and limits. Decide whether the question asks for opinion, discussion, comparison, causes, solutions or multiple answers.

## Practice
Classify: “Why does this happen and what can be done?”

## Suggested answer / rationale
Problems/causes + solutions.
