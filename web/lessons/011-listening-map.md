# BUYE IELTS Module 011: Map and Plan Navigation

**Track:** Listening  
**Goal:** Track movement language.

## Lesson
Prepositions and movement verbs—opposite, beyond, beside, through, left of—are essential for map tasks.

## Practice
From the entrance, the café is beyond the reception desk. Where is it relative to reception?

## Suggested answer / rationale
beyond/after reception
