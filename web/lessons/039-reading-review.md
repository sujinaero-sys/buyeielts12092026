# BUYE IELTS Module 039: Reading Error Review

**Track:** Reading  
**Goal:** Turn wrong answers into patterns.

## Lesson
Classify errors as locating, interpreting, vocabulary, question-type or time-management problems.

## Practice
Record one wrong answer using the five categories.

## Suggested answer / rationale
One category plus a corrective action.
