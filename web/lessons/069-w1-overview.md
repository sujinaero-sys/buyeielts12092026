# BUYE IELTS Module 069: Overview First

**Track:** Writing Task 1  
**Goal:** Identify the biggest patterns before details.

## Lesson
An overview should highlight dominant trends, extremes, major differences or stability without becoming a number list.

## Practice
Given a chart with one category rising sharply and another falling, write the overview.

## Suggested answer / rationale
Rising category + falling category + notable comparison.
