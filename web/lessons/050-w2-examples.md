# BUYE IELTS Module 050: Use Relevant Examples

**Track:** Writing Task 2  
**Goal:** Make examples support the claim.

## Lesson
A useful example is specific enough to illustrate the mechanism but not so detailed that it becomes a story.

## Practice
Create an example for digital learning improving access.

## Suggested answer / rationale
Remote learners in rural areas accessing specialist courses.
