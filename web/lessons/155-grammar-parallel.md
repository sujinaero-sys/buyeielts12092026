# BUYE IELTS Module 155: Parallel Structure

**Track:** Grammar  
**Goal:** Keep lists grammatically balanced.

## Lesson
Items joined by and/or should have matching forms.

## Practice
Fix: “The policy aims to reduce waste, improving recycling and cleaner cities.”

## Suggested answer / rationale
reduce waste, improve recycling and create cleaner cities.
