# BUYE IELTS Module 062: Environment Essay Toolkit

**Track:** Writing Task 2  
**Goal:** Avoid generic environmental claims.

## Lesson
Use specific mechanisms such as emissions, land use, resource consumption or conservation.

## Practice
Explain why efficient transport can help the environment.

## Suggested answer / rationale
Fewer vehicle emissions per passenger.
