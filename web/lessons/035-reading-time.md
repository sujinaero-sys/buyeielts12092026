# BUYE IELTS Module 035: Reading Time Control

**Track:** Reading  
**Goal:** Allocate time according to question difficulty.

## Lesson
Avoid spending several minutes on one stubborn question. Mark it, move on and return if time permits.

## Practice
Set a practical review rule for a difficult item.

## Suggested answer / rationale
Move on after a focused attempt.
