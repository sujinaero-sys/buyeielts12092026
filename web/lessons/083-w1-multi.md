# BUYE IELTS Module 083: Multiple Visuals

**Track:** Writing Task 1  
**Goal:** Connect charts when two visuals appear.

## Lesson
Identify whether the visuals show related measures and write a unified overview.

## Practice
Explain how to organise a bar chart plus table.

## Suggested answer / rationale
Overview first, then grouped details.
