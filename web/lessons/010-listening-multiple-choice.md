# BUYE IELTS Module 010: Multiple Choice Without Guessing

**Track:** Listening  
**Goal:** Eliminate options using the speaker's complete meaning.

## Lesson
An option can contain words you hear but still be wrong. Check the relationship between the words and the speaker's conclusion.

## Practice
Speaker: “The original plan was expensive, so we chose a smaller design.” Which idea is supported: original plan / smaller design / both?

## Suggested answer / rationale
smaller design
