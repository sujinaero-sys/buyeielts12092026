# BUYE IELTS Module 082: Static Charts

**Track:** Writing Task 1  
**Goal:** Describe data without inventing time trends.

## Lesson
If no time is shown, use comparison language rather than rose/fell.

## Practice
Describe two categories where one is larger.

## Suggested answer / rationale
A was considerably higher than B.
