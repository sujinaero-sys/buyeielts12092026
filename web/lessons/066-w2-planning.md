# BUYE IELTS Module 066: Plan in Five Minutes

**Track:** Writing Task 2  
**Goal:** Turn planning into a repeatable habit.

## Lesson
Spend a short period choosing position, two main ideas, support and paragraph order.

## Practice
Create a five-line plan for a city housing prompt.

## Suggested answer / rationale
Position + BP1 + BP2 + example + conclusion.
