# BUYE IELTS Module 075: Map Comparison

**Track:** Writing Task 1  
**Goal:** Describe spatial change.

## Lesson
Use location language and group related changes: added, removed, relocated, converted.

## Practice
Describe a park that gains a café and loses a car park.

## Suggested answer / rationale
Café added; car park converted.
