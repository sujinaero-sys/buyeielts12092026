# BUYE IELTS Module 023: True / False / Not Given

**Track:** Reading  
**Goal:** Separate contradiction from absence.

## Lesson
TRUE is supported; FALSE conflicts; NOT GIVEN lacks enough information. Never use outside knowledge.

## Practice
Passage says the garden opened in 2019. Statement: it opened in spring 2019.

## Suggested answer / rationale
NOT GIVEN
