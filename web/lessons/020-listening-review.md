# BUYE IELTS Module 020: Listening Error Review

**Track:** Listening  
**Goal:** Build a repeatable correction routine.

## Lesson
After every practice, record the question number, mistake type, correct answer and prevention strategy.

## Practice
Make a four-column error log for one listening test.

## Suggested answer / rationale
Question / Error / Cause / Fix
