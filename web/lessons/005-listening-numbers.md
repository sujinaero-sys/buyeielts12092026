# BUYE IELTS Module 005: Handle Numbers and Dates

**Track:** Listening  
**Goal:** Record numerical information accurately.

## Lesson
Separate the number from surrounding speech and confirm whether the speaker changes it.

## Practice
“The fee is 60 pounds—sorry, 16 pounds.” Which figure is final?

## Suggested answer / rationale
16
