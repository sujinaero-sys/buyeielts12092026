# BUYE IELTS Module 070: Bar Chart Comparison

**Track:** Writing Task 1  
**Goal:** Group categories meaningfully.

## Lesson
Compare rather than describe bars one by one. Group similar values and identify extremes.

## Practice
Write two comparison sentences for four categories.

## Suggested answer / rationale
Any accurate grouped comparison.
