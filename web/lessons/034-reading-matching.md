# BUYE IELTS Module 034: Match People and Views

**Track:** Reading  
**Goal:** Track who believes what.

## Lesson
Create a simple name → opinion map before selecting answers.

## Practice
Researcher A favours regulation; Researcher B favours incentives.

## Suggested answer / rationale
A—regulation; B—incentives
