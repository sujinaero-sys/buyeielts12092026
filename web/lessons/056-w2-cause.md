# BUYE IELTS Module 056: Explain Causes

**Track:** Writing Task 2  
**Goal:** Move from surface cause to mechanism.

## Lesson
Ask “why?” twice, then show how the cause produces the outcome.

## Practice
Develop why commuting is stressful.

## Suggested answer / rationale
Time loss → reduced personal time → fatigue.
