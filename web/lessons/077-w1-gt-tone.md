# BUYE IELTS Module 077: Formal and Informal Tone

**Track:** Writing Task 1  
**Goal:** Match tone to relationship.

## Lesson
Use contractions and friendly phrasing only when the situation permits.

## Practice
Classify a letter to a manager versus a friend.

## Suggested answer / rationale
Manager—formal; friend—informal.
