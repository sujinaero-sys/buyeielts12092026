# BUYE IELTS Module 153: Gerunds and Infinitives

**Track:** Grammar  
**Goal:** Use verb patterns correctly.

## Lesson
Some verbs take -ing, others infinitive; some allow both with changed meaning.

## Practice
Complete: “People avoid ____ (drive) at peak times.”

## Suggested answer / rationale
driving
