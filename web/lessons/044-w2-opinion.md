# BUYE IELTS Module 044: Opinion Essay

**Track:** Writing Task 2  
**Goal:** Maintain a consistent position.

## Lesson
If the prompt asks whether you agree, your position should remain clear throughout the essay.

## Practice
Write a one-sentence position on school uniforms.

## Suggested answer / rationale
Any consistent agree/disagree position.
