# BUYE IELTS Module 022: Scan for Evidence

**Track:** Reading  
**Goal:** Locate likely evidence efficiently.

## Lesson
Search for names, dates, unusual nouns and paraphrase signals, then read the surrounding sentences.

## Practice
Find the evidence for a statement about a 2019 launch.

## Suggested answer / rationale
The sentence containing the launch detail.
