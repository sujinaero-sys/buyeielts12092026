# BUYE IELTS Module 047: Problem and Solution

**Track:** Writing Task 2  
**Goal:** Connect a problem to a realistic response.

## Lesson
Explain the cause or consequence before proposing a solution that addresses it.

## Practice
Problem: traffic congestion. Solution: reliable public transport.

## Suggested answer / rationale
Solution targets demand for private car use.
