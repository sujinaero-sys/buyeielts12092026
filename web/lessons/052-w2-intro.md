# BUYE IELTS Module 052: Write a Two-Sentence Introduction

**Track:** Writing Task 2  
**Goal:** Avoid long introductions.

## Lesson
Paraphrase the issue, then state a direct thesis/roadmap only when useful.

## Practice
Create a two-sentence opening for a recycling policy essay.

## Suggested answer / rationale
Issue paraphrase + position.
