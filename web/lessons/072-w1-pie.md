# BUYE IELTS Module 072: Pie Chart Shares

**Track:** Writing Task 1  
**Goal:** Focus on proportions.

## Lesson
Compare the largest/smallest shares and meaningful groups.

## Practice
If A is 45% and B 10%, state the key contrast.

## Suggested answer / rationale
A accounted for 45%, over four times B's share.
