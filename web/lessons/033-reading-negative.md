# BUYE IELTS Module 033: Handle Negative Questions

**Track:** Reading  
**Goal:** Find the one option that does not fit.

## Lesson
Mark three supported options as you prove them, then identify the remaining unsupported choice.

## Practice
Which option is NOT mentioned? Verify each option rather than guessing.

## Suggested answer / rationale
Unsupported option
