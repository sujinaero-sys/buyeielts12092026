# BUYE IELTS Module 086: Avoid Personal Opinion

**Track:** Writing Task 1  
**Goal:** Describe rather than evaluate.

## Lesson
Academic Task 1 is an information report, so avoid claims such as “this is good”.

## Practice
Remove an opinion from a report sentence.

## Suggested answer / rationale
Neutral factual description.
