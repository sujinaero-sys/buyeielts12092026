# BUYE IELTS Module 148: Relative Clauses

**Track:** Grammar  
**Goal:** Add controlled detail.

## Lesson
Use who, which, that and where to combine related information.

## Practice
Join two sentences about a policy.

## Suggested answer / rationale
An accurate relative clause.
