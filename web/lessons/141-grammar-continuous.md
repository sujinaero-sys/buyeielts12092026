# BUYE IELTS Module 141: Present Perfect Continuous

**Track:** Grammar  
**Goal:** Show an activity continuing over time.

## Lesson
Use it for ongoing/recent activity with duration or visible effect.

## Practice
“I have been studying for two hours.” Explain the emphasis.

## Suggested answer / rationale
Duration/ongoing activity.
