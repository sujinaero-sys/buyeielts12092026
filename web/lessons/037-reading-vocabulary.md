# BUYE IELTS Module 037: Context Vocabulary

**Track:** Reading  
**Goal:** Infer unfamiliar words without panic.

## Lesson
Use nearby definitions, contrasts, examples and grammar to estimate meaning.

## Practice
If a word appears after “a process that…” infer that it is likely a noun/process label.

## Suggested answer / rationale
Context-supported meaning.
