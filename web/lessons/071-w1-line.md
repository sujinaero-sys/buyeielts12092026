# BUYE IELTS Module 071: Line Graph Trends

**Track:** Writing Task 1  
**Goal:** Describe movement over time.

## Lesson
Use verbs and nouns for rises, falls, stability, peaks and fluctuations.

## Practice
Describe a line that rises, peaks, then declines.

## Suggested answer / rationale
It rose to a peak before falling.
