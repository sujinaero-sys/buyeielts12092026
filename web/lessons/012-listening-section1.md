# BUYE IELTS Module 012: Section 1: Everyday Transactions

**Track:** Listening  
**Goal:** Build accuracy with practical conversations.

## Lesson
Expect names, addresses, dates, prices and arrangements. Preview the form and predict what information each gap needs.

## Practice
Create five answer-type predictions for a hotel booking form.

## Suggested answer / rationale
Name, date, number, place, time
