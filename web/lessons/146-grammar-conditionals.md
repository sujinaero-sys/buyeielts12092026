# BUYE IELTS Module 146: Conditionals for Arguments

**Track:** Grammar  
**Goal:** Express hypothetical results.

## Lesson
Use real and hypothetical conditional forms to discuss policy and consequences.

## Practice
Write a conditional about public transport investment.

## Suggested answer / rationale
If cities invest..., congestion may decrease.
