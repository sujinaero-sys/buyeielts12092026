# BUYE IELTS Module 084: Task 1 Paragraphing

**Track:** Writing Task 1  
**Goal:** Keep the report easy to follow.

## Lesson
A simple structure is introduction, overview and two detail paragraphs.

## Practice
Group six data points into two logical detail groups.

## Suggested answer / rationale
Two related comparison groups.
