# BUYE IELTS Module 152: Sentence Boundaries

**Track:** Grammar  
**Goal:** Prevent run-ons and fragments.

## Lesson
Use full stops, commas and conjunctions to control sentence boundaries.

## Practice
Fix: “Cities grow rapidly this creates pressure.”

## Suggested answer / rationale
Cities grow rapidly, creating pressure. / Cities grow rapidly. This creates pressure.
