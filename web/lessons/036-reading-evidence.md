# BUYE IELTS Module 036: Evidence First

**Track:** Reading  
**Goal:** Prove an answer before committing.

## Lesson
For every answer, be able to point to the sentence or relationship that supports it.

## Practice
Write one evidence sentence for your chosen answer.

## Suggested answer / rationale
A concise supporting sentence.
