# BUYE IELTS Module 030: Classification Questions

**Track:** Reading  
**Goal:** Match facts to categories.

## Lesson
Create a quick list of category labels and attach each piece of evidence as you find it.

## Practice
Match each invention to its inventor.

## Suggested answer / rationale
Inventor/category supported by passage
